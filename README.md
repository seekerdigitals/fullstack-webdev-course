# fullstack-webdev-course

Solutions for **Coursera — HTML, CSS, and Javascript for Web Developers** (Johns Hopkins University).

Each assignment lives in its own container folder and is hosted with GitHub Pages.

## Assignment 3 — "Food, LLC"

- Source: [`module3-solution/`](module3-solution/)
- Live page: https://seekerdigitals.github.io/fullstack-webdev-course/module3-solution/

Single responsive page built with **Bootstrap 3.3.7**: a navbar with "Food, LLC" brand, a mobile-only hamburger dropdown menu (Chicken / Beef / Sushi), a centered "Our Menu" heading, and 3 responsive food sections (`col-md-4` desktop, `col-sm-6` + `col-sm-12` tablet, `col-xs-12` mobile). All custom styling is in `module3-solution/css/styles.css` — no inline styles.
